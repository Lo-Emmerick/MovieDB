#  🎬 Movie DB
Aplicativo Android para exibição de filmes utilizando a API da TMDB.  
Desenvolvido com arquitetura MVVM, Retrofit e Room.


## 🚀 Funcionalidades
- Listagem de filmes populares  
- Detalhes com elenco, nota e descrição  
- Busca por título de filme  

## 🛠️ Tecnologias utilizadas
- Kotlin
- MVVM
- TMDB API

## 💻 Como rodar o projeto
- Clone o repositório
- Abra o projeto no Android Studio
- Rode o app no emulador ou dispositivo
